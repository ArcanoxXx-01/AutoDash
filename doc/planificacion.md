# Planificacíon (Genereal)

1. **Investigación y Revisión de Literatura:**
    - 🗹 Estudio de los fundamentos de Streamlit
    - 🗹 Análisis de técnicas de procesamiento de lenguaje natural (NLP)
    - Investigación sobre generación de código automática
    - Revisión de proyectos similares o relacionados
    - Redacción del Estado del Arte

2. **Definición del Alcance y Objetivos:**
    - Establecer las capacidades específicas del sistema
    - Definir los tipos de gráficos y visualizaciones que se generarán
    - Determinar las limitaciones y restricciones del proyecto
    - Redaccion del levantamiento de requerimientos

3. **Diseño de la Arquitectura del Sistema:**
    - Componente de procesamiento de lenguaje natural
    - Módulo de generación de código Streamlit
    - Sistema de integración de código en la aplicación existente
    - Lógica de previsualización de dashboards y de integración de código
    - Interfaz de usuario para ingresar prompts y visualizar resultados

4. **Desarrollo del Prototipo:**
    - Implementación del procesador de lenguaje natural
    - Creación del generador de código Streamlit
    - Desarrollo del sistema de integración de código
    - Diseño y construcción de la interfaz de usuario

5. **Entrenamiento y Ajuste del Modelo de NLP (primero debatir con el profe):**
    - Recopilación y preparación de datos de entrenamiento
    - Entrenamiento del modelo de NLP
    - Ajuste y optimización del modelo

6. **Implementación de Funcionalidades Clave:**
    - Generación de diferentes tipos de gráficos (barras, líneas, dispersión, etc.)
    - Soporte para múltiples fuentes de datos
    - Personalización de estilos y temas de los dashboards
    - Manejo de errores y retroalimentación al usuario

7. **Integración y Pruebas:**
    - Integración del sistema generador con la aplicación Streamlit existente
    - Desarrollo de casos de prueba exhaustivos
    - Realización de pruebas de usabilidad y rendimiento

8. **Evaluación y Validación:**
    - Definición de métricas de evaluación (precisión, tiempo de generación, etc.)
    - Realización de experimentos comparativos
    - Análisis de resultados y ajustes necesarios

9. **Documentación y Presentación:**
    - Elaboración de la documentación técnica del sistema
    - Preparación de la tesis escrita
    - Creación de materiales de presentación (diapositivas, demostraciones)

10. **Consideraciones Éticas y de Seguridad:**
    - Análisis de implicaciones éticas del uso de IA para generación de código
    - Implementación de medidas de seguridad para prevenir mal uso del sistema

11. **Extensiones y Trabajo Futuro:**
    - Identificación de posibles mejoras y características adicionales
    - Exploración de aplicaciones en otros dominios o frameworks

12. **Plan de Implementación y Despliegue:**
    - Diseño de una estrategia para el despliegue del sistema
    - Consideraciones para la escalabilidad y mantenimiento
